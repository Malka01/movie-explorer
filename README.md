# 🎬 Movie Explorer

A responsive movie discovery application built with React and the TMDb API.

## Features

- User login UI
- Trending movies
- Movie search
- Load More pagination
- Movie details
- Movie overview
- Genres
- Cast
- YouTube trailers
- Genre filtering
- Release year filtering
- Rating filtering
- Favorites
- LocalStorage persistence
- Light/Dark mode
- Responsive mobile-first UI
- Protected Favorites route
- Jest and React Testing Library tests

## Tech Stack

- React
- Create React App
- React Router
- Axios
- Material UI
- React Context API
- TMDb API
- Jest
- React Testing Library
- LocalStorage
